# Prompts de Elyon en pixel art

Para ver cómo se vería Elyon a escala de juego (Spike 001). Cada bloque se copia entero.

## Cómo usarlos

1. Adjuntá la hoja de personaje de Elyon como imagen de referencia (en Midjourney: `--cref <url>`; en ChatGPT o Gemini: adjuntarla al mensaje).
2. Pegá **un** prompt por vez (una pose por imagen; varias juntas hacen que el personaje cambie).
3. Si la herramienta tiene prompt negativo, pegá también el de abajo.
4. Guardá cada resultado con el nombre sugerido (por ejemplo `elyon_40_quieto.png`) en una carpeta y pasale la ruta al agente: las achica a tamaño real y las pone en el prototipo.

## Prompt negativo (para todos)

```
blurry, anti-aliasing, soft shading, gradients, painterly, 3D render, photorealistic,
inconsistent pixel size, text, watermark, multiple characters, cropped feet, front view
```
